# 🎬 巴西电视剧原声切片与单元自动匹配目录 (`videos/`)

将你下载的**巴西电视剧或电影文件**（`.mp4` / `.mkv` / `.webm` / `.mp3`）以及对应的**葡语字幕文件**（`.srt` / `.vtt`）放到本文件夹中，即可一键提取真实演员原声并自动归类到《大学葡萄牙语 1》的 14 个单元！

## 1. 快速使用步骤

1. **放入视频与字幕**（推荐同名）：
   - 例如：`videos/Coisa_Mais_Linda_S01E01.mp4`
   - 字幕：`videos/Coisa_Mais_Linda_S01E01.srt`（支持纯葡语字幕或中葡双语字幕）
   - *注：如果没有字幕文件，脚本会自动调用本地 `faster-whisper` / `whisper` 进行巴葡语音识别。*

2. **在项目根目录运行提取脚本**：
   ```bash
   python3 process_br_series.py --series "Coisa Mais Linda"
   ```

3. **刷新网页即可点播**：
   - 脚本会自动用 `ffmpeg` 将匹配各课词汇与语法的台词切为独立 `.mp3`（存放在 `audio/br_clips/`），并更新 `br_clips_data.js`。
   - 打开网页进入任意单元，在 **「🎬 巴剧原声实景片段」** 卡片中即可直接点击播放真实巴西演员原声！

## 2. 推荐适合跟读的巴西剧集（语速适中、日常词汇密度高）

- **《Coisa Mais Linda》（最美之物）**：里约热内卢与圣保罗中产日常对话，发音清晰标准，寒暄、点餐、租房、家庭高频词极多（强烈推荐匹配 Unidade 1–8）。
- **《Bom Dia, Verônica》（早安薇罗妮卡）**：圣保罗现代都市悬疑剧，包含大量职场、电话沟通、交通与医疗表达（适合匹配 Unidade 4, 8, 11, 13）。
- **《Avenida Brasil》（巴西大道）**：巴西国民级家庭剧，日常口语、家庭称谓、情感表达地道丰富。
- **《3%》（百分之三） / 《Cidade Invisível》（隐形城市）**：Netflix 原创巴剧，自带高质量官方葡语字幕（`.pt-BR.srt`）。
